# Изменения

## Не выпущено

- Проверка опубликованного пакета выполняет Maven download из отдельного
  проекта: resolver не подставляет артефакт текущей сборки вместо registry.
- Добавлена числовая функция `bit(число, индекс)` в парсер, валидатор и вычисление
  формул и условий. Поддерживаются выражения в аргументах и вложенные вызовы.
- Биты 0–63 извлекаются после преобразования в `long`; результат — 0 или 1.
  Допускаются только конечные целые числа в пределах ±2⁵³ и целые индексы 0–63.
  Отрицательный `byte` сохраняет знак; неверные аргументы отклоняются исключением.
- Сохранены публичные методы, обработка прежних формул и логический смысл `&`/`|`.

## 7.5

- Подготовлена публикация релизов в GitHub Packages по циклу aurora-release;
  новые Maven-координаты: by.aurorasoft:conditional-expression-calculator.
- Добавлены CI, Maven wrapper и mise; сборка на JDK 25 сохраняет Java 11.
- Публикация из develop отключена; релизный CI проверяет версию, CHANGELOG,
  существующие артефакты и происхождение скачанного JAR перед созданием тега.

- Устранена запись значений сообщений в общие токены формул и условий, включая
  внешние условия и зависимости. Параллельный расчёт использует локальные стеки.
- Добавлена явная подготовка SensorCalculator.prepare перед публикацией снимка.
  Без подготовки выражения компилируются локально без автоматического кеширования.
